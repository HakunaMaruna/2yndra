Системное меню управления Linux‑сервером

Скрипт предоставляет интерактивное меню для выполнения типовых административных задач на Linux‑системах (Ubuntu/Debian).
Возможности скрипта

    Обновление системы:

        выполняет apt update;

        предлагает выполнить apt upgrade.

    Установка Docker:

        проверяет наличие curl;

        при необходимости устанавливает curl;

        загружает и запускает официальный установщик Docker.

    Создание ограниченного SSH‑пользователя:

        создаёт пользователя с оболочкой /usr/sbin/nologin (запрет интерактивного входа);

        генерирует случайный пароль;

        выводит пароль для подключения;

        разрешает использование SSH‑туннелей.

    Удаление пользователей:

        показывает список обычных пользователей (UID ≥ 1000);

        позволяет выбрать пользователя по номеру;

        запрашивает подтверждение удаления;

        удаляет пользователя вместе с домашней директорией (userdel -r).
